# FinalDelivery — Cross-dataset comparison

| File | Description |
|------|-------------|
| `viddar_cross_dataset_comparison.ipynb` | Colab notebook: synthetic COCO ViDDAR-style set + transfer evaluation of Options A/B |
| `_build_comparison_nb.py` | Regenerates the notebook (optional) |

Paper: `../Entrega4/ThirdRound/Project_vrva.tex`

## How to run

1. Upload `viddar_cross_dataset_comparison.ipynb` to Colab (GPU / T4).
2. Run cells in order. It reuses ViDDAR checkpoints under `MyDrive/viddar_samed/checkpoints/` if present.
3. Outputs go to `MyDrive/viddar_samed/cross_dataset/`.
